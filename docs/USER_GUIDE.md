# CS 답변 초안 사용 가이드 (CS팀용)

AI가 상품 Q&A 문의, 상품 후기, 고객이 글에 단 댓글에 답변 초안을 미리 써 둡니다. 여러분은 초안을 **읽고, 필요하면 고치고, 승인**하면 됩니다. 승인하기 전에는 고객에게 아무것도 나가지 않습니다.

## 하루 흐름

1. 관리자 화면을 켜 둡니다. 1분마다 카페24에서 새 글을 확인하고, 들어온 글은 바로 초안을 만들기 시작합니다. 한 건에 수십 초쯤 걸립니다. 바로 확인하고 싶으면 오른쪽 위 **지금 확인**을 누릅니다.
2. 새 글이 들어오거나 초안이 준비되면 오른쪽 아래에 알림이 뜨고, 종 모양 버튼에 숫자가 붙습니다. 처음 한 번 종 모양 버튼을 눌러 **맥 알림 켜기**를 누르면, 다른 창을 보고 있을 때도 맥 알림으로 알려 줍니다. 소리는 종 모양 버튼 안에서 끌 수 있습니다.
3. 왼쪽 **검토 대기**부터 처리합니다. AI가 근거를 갖고 쓴 초안들입니다. 위쪽 **문의 · 후기 · 댓글**로 종류만 골라 볼 수 있습니다.
4. 그다음 **확인 필요**를 처리합니다. 불량, 환불 분쟁, 주소 변경처럼 사람이 판단하거나 직접 처리해야 하는 건입니다.
5. 하나를 처리하면 다음 글이 자동으로 열립니다. 목록에서 빨간 점이 붙은 글은 아직 열어 보지 않은 새 소식이 있는 글입니다.

## 검토 화면 보는 법

- **왼쪽**: 고객이 쓴 글, AI가 근거로 쓴 것(정책 문서, 주문번호), AI가 실제로 확인한 내용(주문 조회 결과, 사이즈 계산 결과)
- **노란 상자**: 담당자 확인이 필요한 이유
- **내부 메모**: AI가 남긴 "직원이 처리할 일" (예: 사진 받으면 불량 판정, 주소 변경 처리)
- **오른쪽**: 답변 초안. 바로 고칠 수 있습니다.
- **고객 댓글**: 왼쪽 맨 위에 댓글이 달린 원글과 앞선 댓글이 나옵니다. 승인하면 고객 댓글 바로 아래에 댓글로 달립니다.

## 승인, 수정, 반려 기준

| 이럴 때 | 이렇게 |
|---|---|
| 내용이 맞고 그대로 보내도 된다 | **승인하고 등록** |
| 표현이나 일부 내용만 고치면 된다 | 초안을 고친 뒤 **승인하고 등록** (자동으로 "수정 후 승인"으로 기록) |
| 방향이 틀렸거나 직접 처리해야 한다 | 반려 이유를 적고 **반려 (직접 처리)**. 카페24에서 직접 답해 주세요. 카페24에서 댓글을 달 때 쓰는 이름은 개발 담당자에게 알려 주세요(그 이름의 댓글을 고객 댓글로 잘못 가져오지 않게 설정합니다) |
| 초안이 엉뚱하다 | **초안 다시 만들기** |

## 꼭 확인할 것

- **숫자**: 배송비, 기간, 실측(cm)이 정책과 맞는지 확인합니다. AI는 정책 문서에 있는 값만 쓰도록 되어 있지만, 마지막 확인은 사람이 합니다.
- **날짜 약속**: 재입고일이나 도착일을 약속하는 문장이 있으면 노란 상자에 표시됩니다. 확정된 날짜가 아니면 지워 주세요.
- **사이즈 추천**: 계산 결과는 왼쪽 "사이즈 계산"을 열면 볼 수 있습니다. 고객이 체형 정보를 안 줬다면 AI가 되묻는 답을 씁니다.

## 이런 건 AI가 못 합니다

주소 변경, 환불 처리, 불량 판정, 쿠폰 발급은 AI가 할 수 없습니다. AI는 고객에게 접수 안내만 쓰고, 실제 처리는 담당자가 카페24 관리자 화면에서 합니다.

## 문제가 생기면

- **오류에 글이 있다**: 글을 열어 **다시 만들기**를 누릅니다. 계속 실패하면 직접 답하고 개발 담당자에게 알려 주세요.
- **오른쪽 위가 빨간 "확인 실패"로 바뀌었다**: 카페24 연결(토큰)에 문제가 생긴 것입니다. 개발 담당자에게 알려 주세요. 연결이 돌아오면 저절로 다시 확인합니다.
- **"카페24 등록 실패"가 뜬다**: 승인은 저장되어 있습니다. **다시 등록**을 누르세요.
- **AI 답변이 계속 같은 부분에서 틀린다**: 반려 이유에 적어 주세요. 반려 이유를 모아 정책 문서와 지시문을 고칩니다.
